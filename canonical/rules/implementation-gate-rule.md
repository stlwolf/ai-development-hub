# Implementation Gate
- コードの変更を伴う作業に着手する前に、Plan modeへの切り替えを提案する
- 「対応しよう」「やろう」「進めよう」は方向性の合意であり、実装開始の許可ではない
- 調査・分析の結果を報告した後、そのまま実装に入らない。findings → 方針確認 → Plan mode → 実装の順を守る
- 設計判断の曖昧性が高いタスクでは、Plan mode の前に質問フェーズを挟む。判断基準と進め方は `skill: question-driven-design` を参照
- 例外: 1ファイル数行の軽微な修正で、ユーザーが明示的に「そのまま直して」と指示した場合
