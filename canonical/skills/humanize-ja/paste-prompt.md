# Web 版の Claude や ChatGPT に貼る文

スキルを読み込めない環境（Web 版の Claude・ChatGPT など）で、同じ規則で下書きを直してもらうための文である。下の段落を1つ選び、下書きと一緒に貼る。伝えたい点があれば、段落の前に「伝えたい点: …」と1行書く。

## 日本語の下書き

```text
https://imoz.jp/humanizer.ja.txt を熟読し、ルールに完全に適合するように隅々まで何度も確認して、下の下書きを直してください。ただし、意味・事実・数値・条件・否定・主張の強さは変えず、元に無い情報を足さず、リンク・コード・チェックボックス・表はそのまま保ってください。読み取れない所は直さずに「書き手に確かめたい点」として最大3つ挙げてください。返すものは、直した本文、変えた箇所と理由の一覧、意味が動いた恐れのある箇所、使った規則の URL と全文を読めたかどうか、の4つです。規則の URL が読めなかったときは、本文を直さずにそのことだけを知らせてください。
```

## 英語の下書き

```text
Read https://imoz.jp/humanizer.en.txt carefully, then repeatedly review and revise the draft below until it fully complies with the rules. Do not change the meaning, facts, numbers, conditions, negations, or strength of claims; do not add information that is not in the draft; keep links, code, checkboxes, and tables as they are. Where the intent is unclear, leave the text unchanged and list up to three questions for the writer. Return four things: the revised text, a list of each change with its reason, any places where the meaning may have shifted, and the rule URL with whether you could read it in full. If the URL cannot be read, do not revise the draft; just say so.
```
