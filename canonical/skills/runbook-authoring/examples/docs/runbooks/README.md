# shop の手順書の一覧

架空のサービス `shop` の手順書を並べる。手順書の書き方の決まりは、このリポジトリの文書の決まりに従う。

## 一覧

| 手順書 | 種類 | いつ使うか | 最後に実際の作業で通した記録 |
|---|---|---|---|
| [shop の設定を反映する](shop-config-apply.md) | ずっと使う | 設定ファイルの変更を反映先に入れるとき | まだ無い（見本） |

## 迷ったときの見分け方

| やりたいこと | 手順書 |
|---|---|
| 設定ファイルの変更を反映先に入れる | [shop の設定を反映する](shop-config-apply.md) |
| 反映した設定を前の版に戻す | [shop の設定を反映する](shop-config-apply.md) の「失敗や中断のとき」 |

## 用語

- 反映先: 設定を入れる先のフォルダ。環境変数 `SHOP_STATE_DIR` で決める。
- 版: 設定ファイルの中身から作る12桁の印。中身が同じなら同じ版になる。
- 記録の行: 手順の最後にスクリプトが出す1行。作業の記録に貼る。
- 確かめの番号: スクリプトが出す `OK`・`NG` の行の番号（`C1` など）。手順書の「止まったときに読む表」をこの番号で引く。
