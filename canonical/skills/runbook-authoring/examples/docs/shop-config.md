# shop の設定の反映の仕組み

架空のサービス `shop` の設定（`config/shop.conf`）を、反映先へ入れる仕組みの説明である。作業の手順は [手順書](runbooks/shop-config-apply.md) にある。

## 版

設定ファイルの中身から、12桁の印（版）を作る。中身が同じなら同じ版になるので、同じ設定を2回反映しても何も変わらない。

## 反映先の形

反映先のフォルダは、版ごとのフォルダ `releases/<版>/` と、2つのリンクを持つ。

- `current` は、いま使っている版を指す。
- `previous` は、1つ前の版を指す。戻すときは、この2つを入れ替える。

古い版のフォルダは消さない。戻す先になるからである。

## なぜスクリプトに包むか

反映は、フォルダを作る・設定を写す・2つのリンクを張り替える、の4つの操作からなる。人が4つを順に実行すると、途中で止まったときに状態が分からなくなる。スクリプトは、変える前に操作の行を出して確認を取り、どの操作で止まったかを出す。
