**並行して書き続けられている記録から文を書くときは、書き終えた時点でもう一度原文を読み直す。** 読んだ時点の写しのまま閉じると、古い状態が正本に残る。

#407 で、委譲子が統括の判定の記録（作業層の `.oe/decision-407-judgment.md`）を読み、決定8 を「統括がそのリポジトリの統括に依頼した」と書いた。統括はその1分後に記録を更新し、「消した報告を受け、手元で規則が0件になったことを確かめた」にしていた。decision への SO に、SO を回す時点の記録を写して渡したので、Codex が食い違いを見つけた。自分で見つけたのではない。統括と委譲子は並行して動き、作業層の記録は版を持たないので、更新を知らせる仕組みも無い。

次にどう行動を変えるか。(1) 他のセッションが書く記録を出典にした文は、書き終えたあとに原文の更新時刻か中身を読み直してから commit する。(2) 外部のレビューに原文を渡すときは、渡す時点の原文を写す（自分が最初に読んだ写しを渡さない）。(3) 食い違いが見つかったら、文を直すだけでなく、更新後の主張を自分でも一次情報で確かめる。
