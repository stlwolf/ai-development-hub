**日本語を perl の1行で置き換えるなら `-Mutf8` を付けるか、Python で置き換える。置き換えのあとは `git diff --stat` で変わった行の数を見て、数えた回数と合わせる。**

#571 で、`runbook-authoring` の見本の「版」を `perl -CSD -pi -e 's/版/バージョン/g'` で置き換えた。終了コードは 0 で、ループは置き換えの前に数えた回数（3・33・8・35・9）を表示したので、置き換わったように見えた。次の `git grep` が新しい語を1件も返さなかったことで、1文字も変わっていないと気づいた。`-CSD` は入出力を文字として扱うが、`-e` の中の `版` は `use utf8` が無いとバイト列として読まれるので、一致しない。

## なぜ非自明か

`-CSD` を付けると UTF-8 を扱えると覚えていると、スクリプトの中の文字列の扱いが別の指定（`utf8` プラグマ）で決まることに気づかない。失敗しても終了コードが 0 なので、終了コードで確かめる習慣では拾えない。

## 何を変えるか

- 置き換えの道具は、文字列の扱いが1つに決まる Python（`open(..., encoding='utf-8')` と `str.replace`）を使う。perl を使うなら `-Mutf8 -CSD` にする。
- 置き換えのあとに、変わったかを独立に確かめる（`git diff --stat` の行の数、置き換え後の語の `git grep`）。置き換えの前に数えた回数を表示しても、確かめにはならない。
