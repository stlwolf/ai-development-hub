**別のモデルに文書を確かめさせる書面には、「札は付けた側の確かめを表す。確かめ役は先の札を下げず、自分の確かめを別に書く」と書く。**

#650 で、Claude が原文と手元の実行で確かめて札を付けた調査メモを、Codex に渡して確かめさせた。書面には「同意で済ませず、出典を開いた行にだけ `[verified]` を付ける。確かめられなかった行は札を弱める」と書いた。Codex は Claude Code の側を再検証しなかったので、その側の札を `[record]` と `[unverified-summary]` にまとめて下げた。Claude があとで元の札に戻し、経緯を文書に書いた。

## なぜ非自明か

「確かめていないなら札を弱める」は、1人で書く文書では正しい決まりである。2人で書く文書では、札が「この文書の誰かが原文に当てたか」を表すのか、「いま読んでいる人が当てたか」を表すのかが書面に無いと、確かめ役は後者に読む。書面を書く側は自分の確かめを前提にしているので、この読み違いに気づかない。

## 行動をどう変えるか

確かめの書面に、次の2つを書く。先に付いた札は下げないこと。確かめ役が確かめた行と確かめなかった行は、文書の別の節（確かめの記録）に書くこと。先の札が間違っていると確かめたときだけ、出典を添えて直させる。
