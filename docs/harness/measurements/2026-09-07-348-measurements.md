# #348 の測定値（fork 対比を主証拠に・2026-09-08 更新）

**主証拠は fork 対比である。** 観測の前後比較は補助に降ろした。理由は「後」の腕が育たないことである。owner の作業がほぼ統括を経由し、単独の owner セッションが稀で、しかもアカウント切り替えが近く新しいセッションを作っていない。後 v2 は 2 セッション 99 応答で止まっている。統括の判断（owner 承認・2026-09-08）で、待たずに判定へ進んだ。

**アカウント切り替えで生の転記が失われても読めるように、両方の集計値をこの木に固定した。** 生の応答本文は置かない。

数値だけを置く。**応答の本文は置かない**（別リポジトリ由来の内容を含みうるため、生の転記と抜粋は作業層にだけ残す）。

## 切る点
