## R-1'' 実文脈 fork 対比（12 組・完了）

同じセッションを `--fork-session` で複製し、同じ文脈から同じ発話を style あり / なしで1回ずつ流した。時期と作業内容が同じなので、前後比較では付かない因果の対比になる。

| 指標 | style なし（平均） | style あり（平均） | 差 |
|---|---|---|---|
| 文字数 | 1,347 | 1,114 | -233 |
| 文の数 | 19.3 | 18.3 | -1.1 |
| 接着記号 | 0.67 | 0.00 | -0.67 |
| 内部語の種類数 | 0.50 | 0.17 | -0.33 |
| 英語語の密度 | 9.74 | 8.64 | -1.10 |
| 見出し数 | 3.25 | 2.17 | -1.08 |
| 体言止め | 0.25 | 0.33 | +0.08 |
| 英語 + する | 0.00 | 0.08 | +0.08 |
| 強調記号 | 0.00 | 0.00 | 0 |

- 12 組のうち **10 組**で style ありの方が短かった。
- 接着記号は 12 組すべてで 0 になった。
- **主指標（強調記号）は検定できなかった。** style なしの 12 組すべてで 0 だったためである。
- 複合フラグは style なしで 1/12（8.3%）にとどまり、母集団より低い。fork の題に選んだ発話が軽い問いに偏った。
- 見張り指標が2つわずかに悪化した（体言止め 3件→4件・英語+する 0件→1件）。n=12 では区別できないが、「悪化していない」とは言えないのでそのまま載せる。
- 見出しが減った点は、長さで層別して R-2 で見る。
