## 途中で見つけた自分の誤り（2件）

1. **最初の確認器は、確認用の複製に `--settings` を渡していなかった。** live の設定を受け継ぐので、30本すべてが「期待どおりでない」と出た。確認器が見ていたのは run の設定ではなく確認用の複製の設定である。**これは、この計画で直したばかりの欠陥と同じ型である。**
2. **確認の問いが、v3.1 の文を探させていた。** 「読者は、あなたが今やった作業をその場で見ていない人である」は v3.1 の冒頭で、v4 には無い。v4 の冒頭は「この応答を読むのは、あなたの作業を見ていない運用者である」で、見出しは `# 目的` である。正しい目印で確かめ直した。

見出しは v3.1 が `# 読者`、v4 が `# 目的` で異なる。**この違いは、どちらが乗っているかを見分ける印として使える。**
