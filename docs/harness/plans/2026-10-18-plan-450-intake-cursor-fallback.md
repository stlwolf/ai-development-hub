# #450 issue-intake の別モデルの問い合わせで、Codex が返らないときは Cursor で1回やり直す

## 背景

`issue-intake` の4節は、認識合わせの3つの出力を自分と違うモデルに1回だけ点検させる。Claude で動くセッションでは、そのモデルを Codex（`so-compare --codex-only`）に決めている。2026-10-18、#391 の認識合わせで Codex のレーンが ChatGPT の利用上限で使えなかった。スキルの決まりでは、上限を超えたら「返答が無かった」、手段が無ければ「できなかった」と書いて進むので、別のモデルの点検がそのまま抜けるところだった。統括はその場で Cursor のレーン（`so-compare --cursor-only`）に切り替え、52秒で10件の答えを得て、言い直しでない3件を採った。

**この plan は、#450 の本文と確定版で決まった「やること」3点と「やらないこと」を正本として扱い、覆さない。** この plan が決めるのは、確定版の「issue に書いていないが要ること」3点と本文の「確かめること」2点への答え、4節の表の Codex と Cursor のセッションの行の書き方、スキルの直し方（文面）、受け入れ基準である。

**この plan は設計SO（ゲート2・Codex 1レーン）の指摘で直した。** 何を採り何を退けたかは「設計SO（ゲート2）」節に書く。

- **Codex は stderr に問いの全文を書き出す。** stderr 全体を「利用上限」などの語で検索して理由を決めると、issue 本文にその語があれば誤って当たる（#450 の本文は「利用上限」を含む）。
- **Cursor のアカウントでは Claude のモデルも選べる。** `agent models` の一覧に `claude-opus-5-5-*` などがある。`--cursor-model` か `SO_CURSOR_MODEL` で Claude のモデルを指せば、Cursor のレーンでも Claude と同じ会社になる。「違う会社」と言えるのは既定の composer-2.5 のときだけである。`so-compare` は `${SO_CURSOR_MODEL:-composer-2.5}` で読むので、`SO_CURSOR_MODEL=` と空にして渡せば既定に戻る。
- **終了コード `4` の `unavailable:<コマンド>` には、レーンの CLI でないものがある。** `unavailable:perl`・`unavailable:timeout`・`unavailable:mktemp` は `so-compare` 自身の依存で、切り替え先も同じく動かない。設定値の検査は回すレーンの分だけなので、`invalid:*` が切り替え先でも同じく出るとは限らない（設計SO の指摘3で分かった。`scripts/so-compare.sh` の perl の検査とレーンごとの設定値の検査）。

## 設計判断

### DJ-1 切り替えの規則は「最初のモデルが返らなかったら」と一般の形で書き、表の全行に切り替え先を置く

- **本体の規則**は、どのモデルで動くセッションでも同じ形にする。「最初に問い合わせたモデルから答えが返らなかったら、切り替え先のモデルで1回だけやり直す」。切り替え先の条件は3つで、自分とも最初のモデルとも違うこと、issue の内容を送ることを取り決めが許していること、問い合わせる手段があることである。会社が違うことは、4節の1つ目の箇条と同じく推奨にとどめる（規範は「違うモデル」）。
- **表（`so-compare` の例）**に「切り替え先」の列を足す。表の既定の経路では、3つのモデルがすべて違う会社になる。これは本体の規範より強い性質で、例の側が満たしている（設計SO の指摘2の後半）。

  | セッションのモデル | 最初のレーン | 切り替え先 |
  |---|---|---|
  | Claude | `--codex-only` | `--cursor-only` |
  | Codex | `--claude-only` | `--cursor-only` |
  | Cursor | 今のまま（Claude が動いているなら `--codex-only`、それ以外なら `--claude-only`） | `--cursor-only`（Cursor の composer が動いているなら `--codex-only`） |

  - Codex のセッションでは、最初が Claude、切り替え先が composer-2.5 になる。OpenAI とも Anthropic とも違う。
  - Cursor のセッションで Claude が動いているなら、最初が Codex、切り替え先が composer-2.5 になる。
  - Cursor のセッションで composer が動いているなら、`--cursor-only` は自分と同じモデルになるので、切り替え先は残る1つの `--codex-only` にする。GPT・Gemini など、それ以外のモデルが動いているなら、最初が Claude、切り替え先が composer-2.5 になる。
- **棄却した案**:
  - (a) Claude のセッションの行だけに切り替え先を置き、ほかの行は「切り替えない」にする。issue の文面（Codex が返らないとき）に最も近いが、本体の規則が「最初のモデル」でなく「Codex」に依存する形になり、Codex のセッションで Claude が返らない場合だけ点検が抜ける理由が無い。
  - (b) 切り替え先を表に書かず、本体の規則だけにする。読む側が毎回会社を調べることになり、Cursor のアカウントで Claude のモデルを選ぶ誤りも防げない。

### DJ-2 「返らなかった」は、問いへの答えが読めるかで決め、`so-compare` では終了コードと回答のファイルで見分ける

- **判定の順序**（設計SO の指摘1で直した）: 最初に、問いへの答えが読めるかを見る。読めれば、時間切れやエラーで終わっていても返ったものとし、切り替えずに終わり方を「別モデル」の行に添える。読めないときだけ、返らなかったものとする。最初の案は「エラーで終わった」と「途中で切れていても答えが読めれば返った」を並べていて、指摘を1件出してからエラーで終わった出力（`error_partial`）で、2つが逆の答えを出した。
- **答えが読めない4つの場合**（道具に依らない本体の定義）: 上限の時間内に何も来なかった。エラーで終わり、答えが無かった（利用上限によるものを含む）。出力が空か、空白だけだった。出力がエラーの文言や前置きだけで、問いへの答えになっていない。issue の4つ（利用上限・時間切れ・エラー・空の出力）に「答えになっていない」を足した。`so-compare` は stdout が空でなければ成功と数えるので、エラーの文言だけが stdout に出た場合を拾うためである。
- **「答えになっていない」の範囲**（設計SO の指摘1）: 答えの中身に同意できないことや、指摘の質が低いことは、これに当たらない。これを書かないと、気に入らない答えを捨てて切り替える読みが残る。「漏れは無い」という答えも返ったものとする。
- **切り替えるのは最初の問い合わせだけ**（設計SO の指摘4）: 「使う答えは1つまでで、問い合わせるモデルは2つまで」と書き、切り替え先の失敗からもう一度切り替える読みを防ぐ。issue の「返らなかった試行は1回に数えない」はそのまま残す。
- **`so-compare` での見分け方**（例の側に書く）: レーンが1本の実行では、終了コードが次の意味になる（`so-compare` のスキルの終了コードの表と、`scripts/so-compare.sh` の集計。設計SO も実装と一致すると確かめた）。
  - `2`: そのレーンが失敗した（`timeout_empty`・`error`）。返らなかった。
  - `0` か `1`: 回答のファイル（`<出力のディレクトリ>/<レーン>-stdout.txt`）を読み、答えが読めるかで決める。`1` は `success_empty`（空）・`timeout_partial`・`error_partial`（途中まで出た）である。
  - `4`: 入力を拒否した（レーンを1本も起動していない）。`so-compare` が stderr に出す拒否の行（`Error: <型> …`）の型で、3つに分ける（設計SO の指摘3で直した）。
    - `unavailable:codex`・`unavailable:claude`・`unavailable:agent`: そのレーンの CLI が無い。返らなかったものとして切り替える（9節の行と同じ）。
    - それ以外の `unavailable:<コマンド>`（`perl`・`timeout`・`mktemp`）: `so-compare` 自身が動かないので、切り替え先への手段も無いものとして終える。
    - `invalid:<種別>`: 呼び方の誤りなので、切り替えずに直して打ち直す。直せなければ、問い合わせをしなかったものとして終える。最初の案の「同じ呼び方では切り替え先でも同じく拒否される」は、設定値の検査がレーンごとなので言い過ぎだった。切り替えない理由は「入力の不備を先に直すため」で足りる。
    - 理由は、どれもその拒否の行から書く。レーンを起動していないので、レーンの meta は無い。
- **理由の読み方**（設計SO の指摘5で直した）: レーンを起動したときは、meta（`<レーン>-meta.txt`）の `timeout_status` を基本にする。stderr のファイルの末尾近くに、問いの再掲ではない診断の文言（Codex の利用上限なら `ERROR:` で始まる行）が読めたときだけ、その文言を添える。読めなければ「エラーで終了・詳細不明」のように書く。最初の案は「stderr の最後の行から書く」で、最後の行が空行や後続の警告なら利用上限の行を取り落とす。Codex は stderr に問いの全文を書き出すので、stderr 全体を語で検索して理由を決めない（裏取りの1つ目）。理由は見えた事実で書き、原因は推測しない（`so-compare` のスキルの「空返しの原因を meta から断定しない」）。
- **棄却した案**:
  - (a) stderr の利用上限の文言を見分けの条件にする（確定版が挙げた材料の1つ）。見分けには原因の確定は要らず、文言は CLI の更新で変わる。stderr の文言は理由を書く材料にだけ使う。
  - (b) `timeout_status` だけで見分ける。`success` でも中身がエラーの文言だけという場合を拾えず、`error_partial` で使える答えを捨てる。

  ```

  返らなかったかは、`so-compare` の終了コードと、そのレーンの回答のファイル（`<出力のディレクトリ>/<レーン>-stdout.txt`）で見る。

  - 終了コードが `0` か `1` なら、回答のファイルを読み、問いへの答えが読めるかで決める（上の定義）。`1` は、出力が空だったか、時間切れかエラーで途中まで出たかのどれかである。

  ```

```python
#!/usr/bin/env python3
"""#450 の受入の検査。worktree の root で実行する。
  引数なし: 作業ツリーの SKILL.md を検査する
  引数が commit: その commit の SKILL.md を検査する（変更前は b62d618）
  引数がファイル: そのファイルを検査する（写しの試し用）
全項目が PASS なら exit 0、1つでも FAIL なら exit 1。"""
import difflib, os, subprocess, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import changes as c

F = "canonical/skills/issue-intake/SKILL.md"
BASE = "b62d618"

def load(ref):
    if not ref:
        return open(F, encoding="utf-8").read()
    if os.path.isfile(ref):
        return open(ref, encoding="utf-8").read()
    return subprocess.run(["git", "show", f"{ref}:{F}"], check=True, capture_output=True, text=True).stdout

def sections(text):
    out, name = {}, "(front)"
    for line in text.split("\n"):
        if line.startswith("## "):
            name = line
        out.setdefault(name, []).append(line)
    return out

def sec(secs, prefix):
    for k, v in secs.items():
        if k.startswith(prefix):
            return v
    return []

def first_text_block(lines):
    blk, f = [], False
    for l in lines:
        if not f and l == "```text":
            f = True; continue
        if f and l == "```":
            break
        if f:
            blk.append(l)
    return blk

def content_lines(block):
    return [l for l in block.split("\n") if l and not l.lstrip().startswith("```")]

ref = sys.argv[1] if len(sys.argv) > 1 else ""
text = load(ref)
secs = sections(text)
s3, s4, s9, hub = sec(secs, "## 3."), sec(secs, "## 4."), sec(secs, "## 9."), sec(secs, "## 補足")
fail = 0
def chk(i, exp, act, note=""):
    global fail
    ok = exp == act
    if not ok: fail = 1
    print(f"{'PASS' if ok else 'FAIL'} {i} (expected {exp}, got {act}){' ' + note if note and not ok else ''}")

# 変更を検出する項目（新しい行ごと・範囲の中で全行一致が1回）
n = 0
groups = [(c.C1_NEW, first_text_block(s3), "3節の出力の形の例"),
          (c.C2_NEW, s4, "4節"), (c.C3_NEW, s4, "4節"), (c.C4_NEW, s4, "4節"), (c.C5_NEW, s4, "4節"),
          (c.C6_NEW, s4, "4節"), (c.C7_NEW, s9, "9節"), (c.C8_NEW, hub, "補足")]
for blk, scope, where in groups:
    for line in content_lines(blk):
        n += 1
        chk(f"D{n}", 1, scope.count(line), f"[{where}] {line[:40]}…")
# 位置: C2 の最初の箇条が、固定の問いの引用より後、「返ってきた項目のうち」より前
q = c.C2_ANCHOR_BEFORE.split("\n")[0]
a = c.C2_ANCHOR_AFTER.rstrip("\n")
b1 = c.C2_B1.split("\n")[0]
try:
    pos = int(s4.index(q) < s4.index(b1) < s4.index(a))
except ValueError:
    pos = 0
n += 1
chk(f"D{n}", 1, pos, "C2 の位置")

# 旧文が消えたこと
olds = ["／ 返答なし ／", "上限を超えたら、出力に「問い合わせたが返答が無かった」と書いて進む。",
        "| セッションのモデル | 使うレーン |", "最悪の待ちは codex でおよそ450秒、claude でおよそ360秒になる。",
        c.C7_OLD.rstrip("\n"), c.C8_OLD.rstrip("\n")]
for i, s in enumerate(olds, 1):
    chk(f"N{i}", 0, text.count(s))

# 全文の一致: 変更前に C1〜C8 を当てた期待の全文と、検査するファイルの全文が同じ
# （囲みの削除・矛盾する規則の追記・箇条の移動のような、行の有無では見えない壊れ方を捕まえる）
try:
    expected = c.apply(load(BASE))
    chk("F1", 1, int(text == expected), "期待の全文と一致しない")
except ValueError as e:
    chk("F1", 1, 0, f"期待の全文を作れない: {e}")

# 番兵
base = load(BASE).split("\n")
cur = text.split("\n")
sm = difflib.SequenceMatcher(None, base, cur, autojunk=False)
removed = [l for tag, i1, i2, _, _ in sm.get_opcodes() if tag in ("delete", "replace") for l in base[i1:i2]]
unexpected = [l for l in removed if l and l not in c.OLD_LINES]
chk("S1", 0, len(unexpected), "消えた行: " + " | ".join(u[:40] for u in unexpected[:3]))
chk("S2", 1, cur.count("## 4. 別のモデルへ1回だけ問い合わせる"))
chk("S3", 1, cur.count("  cd <リポジトリの外の一時ディレクトリ> && git init -q && SO_TIMEOUT=180 SO_CLAUDE_TIMEOUT=180 so-compare -f <プロンプトのファイル> -o <出力のディレクトリ> --codex-only"))
sys.exit(fail)
```
