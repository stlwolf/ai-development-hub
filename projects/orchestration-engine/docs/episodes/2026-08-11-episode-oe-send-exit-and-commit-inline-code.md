## oe-send では exit 1 が「宛先が無い」を意味していた

`oe-hookfire` の 1 は「`broken`≥1 を検出した」だが、`oe-send` の 1 は別のものを指している。`lib/delegate-send.sh` の `target pane not found`（生存しない `%N`）と、`lib/delegate-registry.sh` の `no live target matches` / `ambiguous target`（解決できない・曖昧なラベル）である。どちらも「宛先が無い」に収まる。

つまり `--help` と打ち間違いが 1 を返していたことは、#315 と同じ構造の欠陥だった。**呼び出し側が exit だけを見ると、打ち間違いが「子のペインが死んだ」として通る。** `oe-send` は親子委譲の送信口なので、この誤読の costs は実際にある。

`~/bin` への配布対象（`CMD_NAMES` 8件）に `oe-send` は入っていないので、影響は repo 内とパス指定の呼び出しに閉じる。

`extract_message` が、コマンドに **バッククォートまたは `$(` が含まれると解析を諦めて `return 1`** し、呼び出し側はそれを **allow** に倒す。実測した。
