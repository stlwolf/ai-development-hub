# Phase 1 横断振り返り: #28 discover + #29 pane

## 目的

#28 と #29 の個別エピソードには各 Issue 内の振り返りが記録されている。本ドキュメントは **2 Issue を横断して初めて見えるパターン** を抽出し、#30 以降の開発フローに反映する。

## 1. レビュー戦略の進化

### 事実

| | #28 (discover) | #29 (pane) |
|--|----------------|------------|
| 計画段階レビュー | arena-compare 2ラウンド | キックオフ（1.5段階を適用） |
| 実装後 gate | **スキップ** → 事後 so-compare | so-compare gate 実施 |
| Copilot | 未使用 | 9ラウンド / 33件検出 / 29件修正 |
| 最終レビュー | so-compare 1回 | so-compare 再実施 |
| 合計修正件数 | 4件 | 38件 |
| レビュー起因コミット | 1 | 11 |

### 分析

**gate スキップ → 事後回収の教訓が #29 に活きた**: #28 で gate をスキップし `local -n` バグを事後発見した反省から、#29 では so-compare gate を実施。結果として4件の構造的問題（grep 偽陽性、`bc` 依存等）を実装直後に修正できた。

**so-compare と Copilot の補完性が明確**: #29 エピソードの分析どおり、重複はほぼゼロ。

| レイヤー | so-compare が強い | Copilot が強い |
|---------|------------------|---------------|
| 設計 | bash 3.2互換、依存排除、grep 安全性 | — |
| 実装 | — | バリデーション漏れ、移植性、ドキュメント整合 |
| 検出タイミング | 少数・構造的（4件/回） | 多数・局所的（33件/9ラウンド） |

**Copilot 9ラウンドのコスト問題**: push のたびに新レビューが生成され、修正→push→レビュー→修正のループが発生。#29 は12コミット中11がレビュー修正。有用だが時間コストが大きい。

### #30 以降への適用

- **so-compare gate は必須維持**。スキップの常態化を防ぐため、CONVENTIONS.md の gate ルールどおり運用する
- **Copilot ラウンドは上限を意識**: 3ラウンド程度で収束しない場合、残件を Phase 2 バックログに送る判断を入れる。完璧を目指すより、主要な改善を取り込んで先に進むほうが全体最適
- **レビュー順序の標準化**: so-compare（設計レビュー）→ 実装 → so-compare（コードレビュー gate）→ push → Copilot → 最終判断

## 2. 計画精度とスコープ

### 事実

| | #28 | #29 |
|--|-----|-----|
| 計画手法 | arena 2段階 | 1.5段階（発散 arena 省略、キックオフ直行） |
| コミット計画 | ステップ通り | 3段階 → 1コミットに集約 |
| Phase 2 送り | 2件 | 8件 |
| 所要時間 | ~105分（概算と近似） | 体感「時間かかった」 |

### 分析

**#28 → #29 で「1.5段階」が適用された**: #28 の学び（arena ラウンド2 の ROI が低い）が #29 で活きている。ただし #29 は pane 5サブコマンドというスコープの大きさと、レビューループの長さが所要時間を押し上げた。

**Phase 2 バックログの倍増**: #28 の2件 → #29 の8件。実装規模に比例して増えるのは自然だが、バックログが溜まり続けると管理コストが増す。

### #30 以降への適用

- **#30 (notify) は #28 寄りの軽量スコープ**: サブコマンド1つ + Lua統合。arena 不要、キックオフ → so-compare の最短パスで十分と思われる
- **Phase 2 バックログの棚卸しタイミング**: 1-3 完了後（Phase 1 全体完了時点）がバッチ整理の自然なタイミング

## 3. 技術的な繰り返しパターン → ADR-005

#28 と #29 で繰り返し検出された bash 互換性・macOS 移植性の問題を ADR-005 として明文化した。

| 発見元 | 問題 | ADR-005 セクション |
|--------|------|-------------------|
| #28 so-compare | `local -n` bash 3.2非互換 | bash 3.2 互換ルール |
| #28 so-compare | mtime ソートの区切り文字 | （個別修正、汎用ルール化不要） |
| #29 Copilot | BSD sed の `\n` 問題 | macOS 固有ルール |
| #29 Copilot | `echo` → `printf` | macOS 固有ルール |
| #29 so-compare | `${arr[@]}` 空配列展開 | bash 3.2 互換ルール |
| #28/#29 共通 | `timeout` 不在 | macOS 固有ルール（未解決） |

**期待効果**: プラン策定時に ADR-005 を参照することで、レビューでの同カテゴリ指摘を上流で防止する。
