# raw-logs/

4層モデルの「層3: 生ログ」の保管場所。

`wezterm` / `wez` の CLI 出力、`get-text` の生ダンプ、セッション貼り付け、チャットの長文コピーなどをここに一時保管する。抽出（要約・エピソード化・ADR 昇格）が終わったら破棄してよい。

## 運用

1. 一次資料になり得るがリポジトリに載せたくない長文・ログをここに保存する
2. エピソード記録や ADR を書く際の参照材料とする
3. 抽出が終わったら削除可能（TTL: 30〜90日目安）

## 注意

- `.gitignore` で git 追跡対象外
- サイズが大きいためリポジトリには含めない
